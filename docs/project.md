## Project Overview

ApplyLog — Personal Job Application Tracker
Project Description

ApplyLog is a web-based application that allows users to manage, organize, and monitor their job application processes through a centralized dashboard.

Users can register an account, maintain their personal job application records, track recruitment progress, organize company information, and monitor their application history.
Primary objectives

1. Provide centralized job application management.
2. Track recruitment progress.
3. Organize company and job information.
4. Provide an overview of application statistics.
5. Maintain secure user authentication and authorization.
   Target users
   Individuals looking for employment who want to organize their job applications.
   Application scope
   This is a single-user-oriented application.

Each registered user has their own private collection of job applications.

We won't introduce complicated multi-tenant organizations, team collaboration, or enterprise-level permissions.

That keeps the business logic manageable.
